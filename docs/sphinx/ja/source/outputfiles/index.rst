***************************
出力ファイルフォーマット
***************************

``RANK`` はプロセス番号＝レプリカ番号を表します。


``RANK/structure.XXX.vasp``
=================================
各ステップごとの原子配置が VASP の POSCAR ファイル形式で出力されます。
ステップ番号がファイル名の ``XXX`` に入ります。

例::

 Mg8 Al16 O32
 1.0
 8.113600 0.000000 0.000000
 0.000000 8.113600 0.000000
 0.000000 0.000000 8.113600
 Al Mg O
 16 8 32
 direct
 0.011208 0.995214 0.998158 Al
 0.758187 0.240787 0.499981 Al
 ... skipped ...
 0.746308 0.744706 0.233021 O
 0.257199 0.255424 0.771040 O

``RANK/minE.vasp``
==========================
最低エネルギーを与えた原子位置が VASP の POSCAR ファイル形式で出力されます。

``RANK/obs.dat``
=========================
各ステップごとの温度とエネルギーが電子ボルト単位で出力されます。

例::

 0	0.1034076	-41690.28269769395
 1	0.1034076	-41692.06763035158
 2	0.1034076	-41692.06763035158
 3	0.1034076	-41691.98205990787
 4	0.1034076	-41692.74143710456

``RANK/obs_save.npy``
==========================
各ステップごとのエネルギーが電子ボルト単位で出力されます。
``numpy.load('obs_save.npy')`` で、 ``darray`` として読み取ることができます。

例::

 $ python -c "import numpy; print(numpy.load('obs_save.npy'))"
 [[-41690.28269769]
  [-41692.06763035]
  [-41692.06763035]
  [-41691.98205991]
  [-41692.7414371 ]]

``RANK/kT_hist.npy``
========================
各ステップごとの温度（電子ボルト単位）が Numpy バイナリ形式で出力されます。
``numpy.load('kT_hist.npy')`` で、 ``darray`` として読み取ることができます。

例::

 $ python -c "import numpy; print(numpy.load('kT_hist.npy'))"
 [0.1034076 0.1034076 0.1034076 0.1034076 0.1034076]


``RANK/Trank_hist.npy``
===========================
（RXMC のみ）
各ステップごとの温度インデックスが Numpy バイナリ形式で出力されます。
``numpy.load('Trank_hist.npy')`` で、 ``darray`` として読み取ることができます。

例::

 $ python -c "import numpy; print(numpy.load('Trank_hist.npy'))"
 [1 1 1 1 1]


``RANK/logweight_hist.npy``
=============================
(PAMC のみ)
各ステップにおけるNeal-Jarzynski 重みの対数が Numpy バイナリ形式で出力されます。

Example::

 $ python -c "import numpy; print(numpy.load('logweight_hist.npy'))"
 [0 0 0 0 0]


``RANK/acceptance_ratio.dat``
================================
各温度におけるモンテカルロ更新の採択率と試行回数。

- 1列目は温度
- 2列目は採択率（採択回数/試行回数）
- 3列目は試行回数 ``ntrials``
- 4列目は採択回数 ``naccepted``
- 5列目は提案を生成できなかった試行の回数 ``nfail``

``nfail`` は、たとえばグランドカノニカル更新で存在しない原子種の削除を提案した場合など、
配置の更新を提案できなかった試行の数です。
これらは試行回数に含まれ、採択されることはありません。


``logZ.dat``
==============
分配関数の対数 :math:`\log Z_i/Z_0` (:math:`i` は温度点の番号)。

- 1列目は温度 :math:`T_i`
- 2列目、3列目は分配関数 :math:`\log Z_i/Z_0` とその誤差
- 4列目、5列目は直前の温度との比 :math:`\log Z_i/Z_{i-1}` とその誤差

``<name>.dat``
=================
温度ごとの物理量 :math:`O` のカノニカル平均 :math:`\langle O \rangle` とその統計誤差 :math:`\sigma[O]` 。
``name`` は ``[[observer.solver]]`` の ``name`` キーワードで指定した名前です。

- 1列目 は温度 :math:`T_i`
- 2列目、3列目は期待値 :math:`\langle O \rangle` と統計誤差
- 4列目、5列目は2乗の期待値 :math:`\langle O^2 \rangle` と統計誤差
- 6列目、7列目はゆらぎ :math:`\langle O^2 \rangle - \langle O \rangle^2` と統計誤差

   - 例えばエネルギーのゆらぎは熱容量 :math:`C` と次のようにして結びついています: :math:`k_B T^2 C = \left[ \langle E^2 \rangle - \langle E \rangle^2 \right]`


能動学習（ ``abics_mlref`` ）の出力ファイル
==================================================

``abics_mlref`` は :math:`n` 回目の能動学習ステップの入出力を ``ALn`` ディレクトリ（ ``AL0``, ``AL1``, ...）に出力します。
``AL0`` はランダムに生成した配置、 ``AL1`` 以降は直前のモンテカルロ計算 ``MC(n-1)`` から取り出した配置に対応します。
``RANK`` は ``[mlref]`` セクションの ``nreplicas`` で指定したレプリカ番号です。

``ALloop.progress``
--------------------------
能動学習ループの進行状況。
``abics_mlref`` 、 ``abics_train`` 、 ``abics_sampling`` が各ステップの完了時に
``AL0`` 、 ``train`` 、 ``MC0`` 、 ``AL1`` 、 ... を順に追記し、次に実行するべきプログラムの判定に用います。

``rundirs.txt``
--------------------------
第一原理計算ソルバーを実行するべき入力ディレクトリ（ ``ALn/RANK/inputXX/baseinputK`` ）の一覧。
``abics_mlref`` が入力ファイルを生成するたびに書き直されます。

``ALn/RANK/inputXX/``
--------------------------
配置 ``XX`` に対するソルバーの入出力。
``XX`` は、 ``AL0`` では通し番号、 ``AL1`` 以降では取り出し元のモンテカルロ計算のサンプル番号
（ ``MC(n-1)/RANK/structure.XX.vasp`` に対応）です。

- ``initial.vasp``: 摂動（ ``[mlref.solver]`` の ``perturb`` ）を加える前の原子配置
- ``baseinputK/``: 第 ``K`` 段のソルバーの入力ファイルと出力ファイル（ ``[mlref.solver]`` の ``base_input_dir`` に複数のディレクトリを指定した場合、段ごとに作られます）

``ALn/RANK/structure.XX.vasp``
-----------------------------------
ソルバーの計算（構造最適化）後の原子配置。 ``abics_train`` の訓練データとなります。

``ALn/RANK/energy_corr.dat``
-----------------------------------
取り出した配置ごとの、機械学習モデルによる予測エネルギーと第一原理計算ソルバーによる参照エネルギー（電子ボルト単位、スーパーセルあたり）。
機械学習モデルの精度を確認するための出力で、横軸を参照エネルギー、縦軸を予測エネルギーにして散布図を描くと、
対角線からのずれとして精度を見ることができます。

- 1列目は機械学習モデルによる予測エネルギー（モンテカルロ計算時の値）。 ``AL0`` ではモデルがまだ存在しないので ``NaN``
- 2列目はソルバーによる参照エネルギー
- 3列目は配置の番号 ``XX``

例::

 -93.40812444 -93.1635694601349 0
 -93.48409204 -93.32726602032281 8
 -93.7486019 -93.81712285031085 17

``ALn/RANK/relax_max.dat``
-----------------------------------
（ ``AL1`` 以降）配置ごとの、 ``initial.vasp`` からソルバー計算後の構造までの原子変位の最大値。
1列目は最大変位を示した原子の番号、2列目はその変位（オングストローム単位）です。
摂動 ``perturb`` の分も含まれます。

``ALn/convergence.dat``
-----------------------------------
（ ``AL1`` 以降）そのステップでの機械学習モデルの誤差統計。
``energy_corr.dat`` の 2 列の差をレプリカごと、および全レプリカをまとめて集計したものです。
同じ表が ``abics_mlref`` のログにも出力されます。
能動学習ループを続けるかどうかの判断材料として使えます。

- 1列目はレプリカ番号（最終行の ``all`` は全レプリカ）
- 2列目は集計した配置数
- 3列目は二乗平均平方根誤差（RMSE）
- 4列目は平均絶対誤差（MAE）
- 5列目は絶対誤差の最大値
- 6列目は最大誤差を与えた配置の番号 ``XX``

誤差の単位はエネルギーと同じ（スーパーセルあたりの電子ボルト）です。

例::

 # AL1: errors of the model energies against the reference solver
 # (per supercell, in the units of energy_corr.dat)
 # replica  n  rmse  mae  max_error  max_error_sample
 0  10  0.256721  0.210012  0.465759  61
 1  10  0.213205  0.140375  0.513428  0
 all  20  0.235968  0.175193  0.513428  0

``ALn/parity.png``
-----------------------------------
（ ``AL1`` 以降、matplotlib がインストールされている場合のみ）
``energy_corr.dat`` のパリティプロット。横軸が参照エネルギー、縦軸が機械学習モデルの予測エネルギーで、
レプリカごとに色分けし、対角線を目安として描きます。

``ALn/baseinput.progress``
-----------------------------------
（ ``base_input_dir`` を複数指定した場合）完了したソルバー計算の段の番号。
